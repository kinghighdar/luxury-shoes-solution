A.K Luxury Shoes Solution Company

Five User Stories

1. View Available Shoes

As a customer, I want to view available shoes so that I can choose my preferred design.

2. View Prices and Sizes

As a customer, I want to see shoe prices and available sizes so that I can decide what to buy.

3. Place an Order

As a customer, I want to place an order easily so that I can purchase my preferred shoes.

4. Contact the Company

As a customer, I want to contact the company through WhatsApp so that I can ask questions and place orders.

5. Manage Products

As the business owner, I want to add new shoes and update product prices so that customers can see the latest products and prices.
